## Installation & Setup

**Prerequisites:**
- Android Studio
- Flutter SDK
- Emulator: Medium Phone API 36.0

**Installation Steps:**
1. Clone the repository from GitHub: `EyalMK/Android-App-Final-Project`
2. Open the project in `Android Studio`
3. Install dependencies: `flutter pub get`
4. Run the application: `flutter run`

Or run directly through Android Studio targeting the specified emulator
